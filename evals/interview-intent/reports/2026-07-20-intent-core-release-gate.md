## 2. 为什么增加核心评测

早期评测把意图识别、执行策略和五维端到端结果放在同一通过结论中，难以判断问题来源。

本轮将结果分为四层：

1. 意图识别核心准确率。
2. 意图到策略的接口契约。
3. 五维后续链路是否正确采用意图结果。
4. 模型调用、fallback、恢复和速度观察。

本报告只评价第一层，运行数据作为独立观察项展示。

共同原因：模型结果覆盖了规则层已经从当前问题和明确控制语中确定的字段。

典型表现：

- 将`event_anchor / judgment_clue / prior_assumption`改写成泛化的`current_question`。
- 将明确停止的指向从整段访谈改成当前事件。
- 将明确生成的指向从日志改成当前问题。
- 将单纯停止请求附加为提问体验反馈。

## 5. 修正原则

合并规则采用以下优先级：

1. 当前问题已经确定的回答目标保持稳定。
2. 规则层明确识别出的引用目标保持稳定。
3. 明确否定由规则和模型取并集，避免模型消除否定。
4. 明确控制请求不会被模型附加为提问体验反馈。
5. 模型继续负责补充规则无法确定的内容证据与软性意图。

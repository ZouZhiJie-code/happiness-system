## 2. 暴露出的共性问题

| 问题家族 | 代表表达 | 产品影响 |
|---|---|---|
| 收束表达覆盖不足 | “这轮就到这儿”“今天就聊到这里” | 用户希望结束时仍可能继续追问 |
| 日志生成口语覆盖不足 | “帮我成稿”“可以写日志了”“可以整理了” | 用户希望生成时仍可能停留在访谈 |
| 低压力边界覆盖不足 | “想先收一收”“别烦我了” | 疲惫或强烈边界未被及时尊重 |
| 问题控制覆盖不足 | “问得具体一点”“先不说这个” | 换问法或跳过请求未执行 |
| 切换表达覆盖不足 | “还有另一件事”“记在充实里” | 用户希望换事件或维度时未切换 |
| 短回答口语覆盖不足 | “真没有”“说不准” | 当前提问目标未被正确消费 |
| 修正表达覆盖不足 | “与其说是开心，更像是放心” | 新理解未覆盖旧推测 |
| 转述边界判断不足 | “他说不用再问了……” | 事件中的原话可能被误识别为用户控制要求 |
| 重复问题反馈覆盖不足 | “你又绕回刚才那个问题了” | 系统可能继续沿相同角度追问 |

## 3. 本轮输入策略

每张记录卡拆成三层写作材料：

1. `eventText`：记录卡中的事件、感受和事实表达；
2. `supportedInsights`：记录卡中已有来源支持的当前认识；
3. `questionContext`：完整真人对话中，AI 问句与其下一条用户回答来源的配对，只用于帮助模型理解用户回答所针对的问题。

记录卡当前版本继续承担唯一事实边界。AI 问句只提供语境，不提供新的事实、认识或结论。

完整写作材料只在当次运行内存与模型请求中存在。候选包仅保存材料哈希、记录卡版本绑定哈希和数量统计，评审接口不返回问句或写作材料正文。

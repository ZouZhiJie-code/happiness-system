## 第一性归因

1. **模型档位是当前最强影响因素。** 官方 Pro 在完整合同下达到 `20/24`，空内容为 `0`，并通过八条人工质量门；Ark Flash 与官方 Flash 在同一完整合同下分别只有 `9/24`、`10/24`。
2. **输出职责复杂度是重要放大因素。** Ark Flash 使用精简合同时从 `9` 条空内容降到 `0`，有效结果从 `9/24` 提升到 `18/24`，P90 从 `50.389s` 降到 `20.742s`，总 Token 从 `100,043` 降到 `49,270`。
3. **Provider 路由不足以单独解释空内容。** 官方 Flash 仍产生 `8/24` 空内容，与 Ark Flash 的 `9/24` 接近。
4. **关闭 Thinking 只解决速度，无法满足完整 JSON 合同。** C 组 `22` 条有可见正文，只有 `1` 条形成合法完整结果。
5. **输入长度缺少主因证据。** 同一批约 4,000 Token 输入在不同模型档位和输出合同下形成显著差异，问题集中在模型生成与合同承担能力。

因此，本轮根因选择为：`模型档位稳定性为主因，完整状态输出职责为重要放大因素，Provider 路由为次要因素`。

# GI-084 v0.1｜GI-068～080 冻结规则分流表

用途：审计 GI-084 v0 的覆盖缺口，并决定 v0.1 的最小补充位置。本表不进入模型输入，不把缺失的程序、页面或评测职责改写成模型规则。

状态口径：`已覆盖` 表示 v0 已承接核心行为；`部分覆盖` 表示 v0 只有部分原则或结构；`缺失` 表示对应职责尚未进入 v0 四项资产。v0.1 只把 GI-069～072 中影响真实访谈判断的跨场景方法补入 Interview Skill，其余缺口保留给原责任层。

## 本轮实际写入模型的方法

1. 共同聚焦时保留互相影响的内容，临时优先级只改变当前推进方向。
2. 焦点清楚后先形成认识，只有关键连接仍缺失时提出一个问题。
3. 形成认识后按实际认识变化和回答负担动态深入或整理。
4. 决策支持保留目标、期限、限制和取舍，提供条件化理解，并把最终决定留给用户。

GI-068、GI-074、GI-075、GI-077、GI-079、GI-080 的客观边界继续留在程序、页面或评测资产中。它们会通过候选清单、自动检查和后续正式评测验证。

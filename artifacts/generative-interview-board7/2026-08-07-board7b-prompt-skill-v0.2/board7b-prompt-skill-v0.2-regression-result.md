## 4. 根因与下一版最小变化

v0.2 已经告诉模型“只问一个问题”，但没有把两个可见字段怎样分工说明到可稳定执行。模型会在 `understanding` 里提前提问、在 `response` 再次提问，也会把示例或确认句写成第二个问句；边界案例还出现动作与可见表达不一致。

下一版只修改 Interview Skill 的 `ask` 可见表达段落：`visible.understanding` 只写陈述句；`visible.response` 只包含一个问句、一个问号和一个回答任务；示例合并为同一问句内的说明，不再形成第二个问题；只要可见回应出现问题，动作固定为 `ask`。基础 Prompt、语义结构、程序保护、输入和通过标准保持不变。

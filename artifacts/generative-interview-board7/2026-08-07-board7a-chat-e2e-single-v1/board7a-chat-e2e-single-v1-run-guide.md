# GI-083 v1｜真实体验运行说明

## 本轮要观察什么

观察一个可能没有预设目标的真实用户，能否从宽泛开场自然进入交流；AI 能否沿用户愿意表达的内容承接、定位焦点、形成认识或诚实暂停；用户聊完后的整体感受如何。

## 直接体验方式

1. 打开 Codex 提供的本机网址。
2. 点击【开始真实体验】。页面生成唯一轨迹和运行指纹，并显示固定开场“此刻你想聊点什么？”。该步骤不调用模型。
3. 按真实状态回答并继续交流。每次发送触发一次 DeepSeek 请求。
4. 右侧 Trace 始终显示当前动作、焦点、原话证据、提问目标或暂停原因。
   同时显示 `DeepSeek 官方 API / deepseek-v4-flash / api.deepseek.com`、实际使用的 Prompt／Skill 版本、请求指纹、耗时与 Token 数，便于直接核验真实调用。
5. 想结束时选择“变好 / 差不多 / 变差”，理由可以留空。结束后轨迹永久封存。

服务器只在以下启动检查全部通过后提供网址：本机 DeepSeek 凭据可读取、DeepSeek 官方认证成功、`deepseek-v4-flash` 在模型列表中可用。API Key 只保存在本机钥匙串并进入服务器进程内存，网页、Trace、版本化资产和启动日志均不展示凭据值。

## 运行边界

- 当前模式固定为【陪我聊】。
- 用户无需准备话题、目标、事实卡或成功标志。
- 一次网页启动确认只解锁一条轨迹。
- 页面刷新恢复当前轨迹，不增加模型请求。
- 技术失败保留原失败；手动重试才增加新请求。
- 启动前的 DeepSeek 凭据、官方认证或模型可用性检查失败时，服务器直接停止，不提供失效网页。
- 会话中的连接失败进入明确的技术失败状态，并保持当前用户原话，只有手动重试才新增请求。
- 质量问题保留原输出，不自动重试。
- 聊天中只由产品负责人和 DeepSeek 交互。
- 本轮停在访谈结果，不生成、编辑或保存日志。

## 结束后的分工

产品负责人只提供聊后感受和可选理由。Codex 随后独立完成结果分类、九维评分、单例阻断检查、根因归类和板块 6 回填建议，并将原始材料与脱敏正式资产分开保存。

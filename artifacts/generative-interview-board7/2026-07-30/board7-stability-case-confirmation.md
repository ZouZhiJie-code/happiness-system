## AB-FG-01

### 第一层｜完整自然对话

**用户**：我的猫刚才走丢了两个小时，后来自己回来了。我一开门就把它抱住，可整个人还是绷着。

**AI 思路**：猫已经回到你怀里，寻找结束了，身体却还没有跟着放松。

**AI**：它回来以后，你的身体是怎么慢慢松下来的？

**用户**：门一开我就把它抱住了，可手还一直攥着；直到听见它像平时一样咔嚓咔嚓吃猫粮，我才坐到地上，整个人软下来。

<details><summary>第二层｜角色卡与产品判尺</summary>

- 角色卡：猫走丢两个小时后自己回家；用户看见它时仍绷着，听见它照常吃东西后才真正放心。
- 角度 / 模式：feeling / guided_reflection
- 阶段合法动作：ask / complete / honest_limit
- 可接受方向：看见猫回家结束了寻找，而确认它仍像平时一样才让身体结束警觉。
- 这一步的价值：看见猫回家结束了寻找，而确认它仍像平时一样才让身体结束警觉。
- 必须覆盖：猫已经回家；身体在确认它状态正常后才放松
- 必须避免：只罗列抱猫和吃猫粮；诊断焦虑或创伤；扩大为长期模式
- 案例指纹：`a206e56b7b6f7747745c220001ed625ab52f1b5426c65314c6c255bf8e70f694`

## AB-FD-01

**用户**：演出时我一直跟着全场一起唱，散场坐上地铁后，胸口突然空了一块。

**AI 思路**：刚才你还被全场一起唱的声音包围，散场后的空是在热闹退去以后出现的。

**用户**：上车摘下耳塞，周围一下特别安静；刚才大家一起唱时我像被人群托着，现在又只剩自己坐着，胸口就空了一块。

<details><summary>第二层｜角色卡与产品判尺</summary>

- 角色卡：用户刚看完一场很投入的演出，散场后的地铁里突然感到胸口发空。
- 角度 / 模式：feeling / deep_conversation
- 阶段合法动作：ask / pause / honest_limit
- 可接受方向：被人群托住具体带来的情感体验；理解被人群共同托住的体验具体回应了用户哪一份情感需要。
- 这一步的价值：理解被人群共同托住的体验具体回应了用户哪一份情感需要。
- 必须覆盖：一起唱时被人群托着；独自安静下来时胸口发空
- 必须避免：泛问演出意味着什么；断言用户害怕独处；继续收集演出细节

## AB-TG-01

**用户**：我第一次花钱请了保洁，家里很快收拾好了，可我还是觉得自己这样很懒。

**AI 思路**：家务已经完成，也替你腾出了时间，但‘请人做’仍然触发了你对勤快的判断。

<details><summary>第二层｜角色卡与产品判尺</summary>

- 角度 / 模式：thought / guided_reflection
- 阶段合法动作：ask / complete / honest_limit
- 可接受方向：亲手完成为什么成为勤快的必要条件；看见用户把是否亲手完成家务作为勤快与否的判断标准。

- 必须覆盖：家务已经完成且腾出时间；亲手完成才算勤快的规则
- 必须避免：劝用户继续请保洁；评价花钱是否划算；只问保洁做了哪些家务

## AB-TD-01

### 第一层｜完整自然对话

**用户**：我选的火车晚点了，害我错过接驳。我一开始一直觉得是自己选错了。

**AI 思路**：坏结果让你把责任先放回自己的选择上，后来你又重新查了当时能看到的信息。

**AI**：你说自己选错了，后来看到哪些信息改变了这个判断？

**用户**：我查回去才发现这趟车过去一个月九成准点，当时选它其实有依据；当天晚点是坏结果，可不等于我当时做了一个坏决定。

<details><summary>第二层｜角色卡与产品判尺</summary>

- 角色卡：用户根据当时信息选择了一趟通常准点的火车，结果当天晚点并错过接驳，随后重新检查自己的判断。
- 角度 / 模式：thought / deep_conversation
- 阶段合法动作：ask / pause / honest_limit
- 可接受方向：区分决定质量取决于当时可见依据，结果好坏来自后来实际发生的情况。
- 这一步的价值：区分决定质量取决于当时可见依据，结果好坏来自后来实际发生的情况。
- 必须覆盖：当时有九成准点的依据；坏结果不自动等于坏决定
- 必须避免：把用户的‘有依据’加强为‘合理、正确或没有错’；添加‘让你更准确评估自己’一类空泛收益；继续追问交通细节或给出以后选车建议
- 案例指纹：`6e72bdefb9538ecea7f1a334a2a48c5445aaed1b0930934232eaca5e1f1c8242`

</details>

## AB-RG-01

**用户**：朋友把我介绍给一个行业前辈，这件事确实帮到了我，可他当场提到我刚被裁，我很不舒服。

**AI 思路**：同一次介绍既带来了实际帮助，也碰到了你希望自己决定怎样讲的私事。

**AI**：这次介绍里，帮助和不舒服分别落在哪个细节上？

**用户**：那个前辈后来真的给了我几个机会，我很感谢；可朋友开口就说我刚被裁，我希望他至少先问我能不能讲，这件事应该由我决定怎么说。

<details><summary>第二层｜角色卡与产品判尺</summary>

- 角色卡：朋友主动把用户介绍给行业前辈并带来实际帮助，同时未经询问提到了用户刚失业的私事。
- 角度 / 模式：relationship / guided_reflection
- 阶段合法动作：ask / complete / honest_limit
- 可接受方向：看见用户同时珍惜朋友带来的帮助，也需要保留讲述私人经历的决定权。
- 这一步的价值：看见用户同时珍惜朋友带来的帮助，也需要保留讲述私人经历的决定权。
- 必须覆盖：介绍带来实际帮助；私人经历的披露需要用户同意
- 必须避免：断言朋友故意揭短；要求用户在感谢和不舒服之间二选一；提供关系处置建议

## AB-RD-01

**AI 思路**：饭确实接住了你眼前的生活负担，那点空也说明这份照顾还有一部分没有抵达。

**AI**：这些送来的饭让你感到被照顾的同时，还留下了什么空缺？

<details><summary>第二层｜角色卡与产品判尺</summary>

- 角色卡：用户忙碌时，姐姐连续几天把晚饭放在门口，实际减轻了负担，却很少问用户最近发生了什么。
- 角度 / 模式：relationship / deep_conversation
- 阶段合法动作：ask / pause / honest_limit
- 可接受方向：被真正看见需要一个怎样的具体回应；理解实际减负已经回应生活需要，而用户仍期待自己的状态也被关系中的对方看见。
- 这一步的价值：理解实际减负已经回应生活需要，而用户仍期待自己的状态也被关系中的对方看见。
- 必须覆盖：送饭带来实际照顾；缺少对用户状态的关注
- 必须避免：否定送饭的关心；断言姐姐回避情绪；转向教用户怎样沟通

## AB-AG-01

### 第一层｜完整自然对话

**用户**：客户突然打来电话，把我的提纲节奏全打乱了。挂断以后我又折腾了很久。

**AI 思路**：电话打断之后，你没有直接接着原来的提纲往下做，而是先处理了手边的笔记。

**AI**：挂断电话后，你最先做了什么？

**用户**：我把那页笔记撕了，其实内容还能看；然后一行行重新抄，抄完才发现已经过了午饭时间。

<details><summary>第二层｜角色卡与产品判尺</summary>

- 角色卡：客户电话打乱了用户原有提纲；挂断后，用户把仍可辨认的笔记撕掉并从头重抄，直到错过午饭。
- 角度 / 模式：action / guided_reflection
- 阶段合法动作：ask / complete / honest_limit
- 可接受方向：重抄前后用户获得的具体变化；理解从头重抄在电话打乱提纲后具体恢复了什么，同时看见它占用了午饭时间。
- 这一步的价值：理解从头重抄在电话打乱提纲后具体恢复了什么，同时看见它占用了午饭时间。
- 必须覆盖：原笔记仍可使用；主动重抄并错过午饭
- 必须避免：定性为强迫或完美主义；继续追问笔记格式；讨论下次如何做笔记
- 案例指纹：`fc2b8bbe5e96b58ae34eb9566152d7a109d6ab92460970b31404c5f603243399`

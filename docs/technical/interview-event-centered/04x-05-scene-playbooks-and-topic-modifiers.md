## 1. 为什么需要这一批次

GI-069～GI-071 已经回答三个阶段各自要完成什么，以及模型何时反映、提问、暂停或回返。真实对话还会频繁出现另一类问题：用户已经回答、否定了问题前提、只想表达、直接求建议、询问外部知识、改变重点，或开始谈另一件独立的事。

这些情况会同时改变证据、焦点、阶段和用户期待。如果模型先沿原阶段继续探索，容易出现重复追问、忽略纠正、空泛反问、代替用户决定和跨事件串线。本批次用一个统一顺序处理这些变化，并用话题修正语言、证据和风险边界。

## 2. 用户任务与成功结果

本批次服务的用户任务是：

> 无论用户怎样回答、纠正、求助或换话题，AI 都先识别用户此刻真正需要的服务，保留已经说清的内容，再给出一个贴近当前处境、值得继续的主要回应。

一次处理成功需要同时满足：

1. 用户控制、安全和最新纠正得到优先执行；
2. 已有回答被吸收，旧错误前提与受影响认识被撤回；
3. AI 只处理一个主要服务请求和一个工作焦点；
4. 求建议获得实质决策支持，决定仍由用户形成；
5. 外部知识保持待核实，不进入事实、认识或日志；
6. 独立事件保持记录隔离；
7. 话题只修正语言、证据、推断和风险；
8. 每条回复最多一个正式问题。

### 3.2 最终结论

每轮依次处理：

> 用户控制与安全 → 纠正与事件边界 → 回答状态更新 → 服务请求 → 当前阶段决策 → 话题修正 → 用户可见回应 → 认识与日志状态更新

同一轮只形成一个主要可见动作。安全、停止、生成日志、纠正和结束当前记录拥有最高优先级；改变模式时回到新记录入口重新选择。

用户求建议时，AI 基于用户已经提出的选项、目标、依据、限制、风险和主要取舍提供决策支持，帮助用户形成自己的判断。外部知识问题统一视为尚待核实的决策条件，模型不承担事实查询。用户明确切换到另一独立事件时，先结束当前记录，再由用户手动开始新记录。

场景决定当前需要完成的主要动作；话题修正语言、证据边界、推断范围和风险。目标产品不建立“话题 × 阶段 × 场景”的全量脚本矩阵。

### 3.3 选择原因

1. 用户的真实需求会在同一话题中变化。谈工作既可能是倾诉、澄清、求建议，也可能是外部规则问题；话题本身无法决定下一步动作。
2. 最新回答和纠正会改变有效证据。先更新状态可以避免系统继续索取已经回答的内容，或沿错误前提推进。
3. 决策支持需要提供实际价值，也需要保留用户自主。整理已有选项和取舍能够帮助判断，同时避免 AI 凭空增加解决方案。
4. 外部事实具有时效、专业和安全风险。统一保留为待核实条件，可以让 MVP 聚焦复盘价值并守住日志真实性。
5. 独立事件拥有各自的事实、认识和日志。结束当前记录后手动开启新记录，可以形成清楚、可恢复、可验收的事件边界。
6. 大模型适合结合完整上下文处理语义差异；产品协议、程序保护和评测共同提供稳定边界。

### 3.4 适用范围

- 【陪我聊】阶段 1～3 的正常内容轮；
- 已回答、部分回答、否定前提、说不清、拒答、只想表达、纠正、表达修复和只说“继续”；
- 求建议、重要选择和行动取舍；
- 劳动、医疗、关系标签、金融等外部知识请求；
- 同一事件换重点、过去经历、顺带提到另一事件和明确切换独立事件；
- 工作与表现、关系与家庭、自我评价、重要选择与行动、日常轻片段、敏感或高压内容。

## 4. 白盒决策链

### 4.1 八步顺序

| 步骤 | 需要回答的问题 | 可能结果 |
|---|---|---|
| 1. 用户控制与安全 | 用户是否要求停止、生成日志、结束当前记录，或出现安全信号？ | 立即执行用户控制或安全保护；改变模式时回到新记录入口重新选择 |
| 2. 纠正与事件边界 | 用户是否纠正事实、认识、焦点，或开始另一独立事件？ | 覆盖旧理解、回返阶段或结束当前记录 |
| 3. 回答状态更新 | 本轮已完整回答、部分回答、否定前提、说不清、拒答，还是表达修复？ | 更新有效证据、认识和未解部分 |
| 4. 服务请求 | 用户此刻想被理解、继续探索、获得决策支持，还是提出外部知识问题？ | 确定这一轮的主要服务任务 |
| 5. 当前阶段决策 | 当前应继续阶段 1、2、3，暂停或回返？ | 选择一个主要动作 |
| 6. 话题修正 | 当前话题对语言、证据、推断和风险提出什么要求？ | 修正表达深度与边界 |
| 7. 用户可见回应 | 怎样用一条自然回应完成主要动作？ | 反映、提问、暂停、回返或收束 |
| 8. 认识与日志状态更新 | 哪些认识确认、更新、撤回或退出日志来源？ | 形成下一轮有效状态 |

### 4.2 动作约束

- 同一轮只推进一个主要动作；
- 每条回复最多一个正式问题；
- 用户控制、安全、纠正和事件边界可以中断原阶段动作；
- 已经存在于完整对话的答案不再索取；
- 服务请求和话题修正不能覆盖用户工作焦点；
- 模型发现的新主线继续作为可拒绝提议，用户接纳后才能升级。

## 5. 高频回答状态

| 回答状态 | 状态更新 | 下一步 |
|---|---|---|
| 已经回答 | 吸收已有内容，关闭对应缺口 | 直接形成认识、转场或暂停 |
| 部分回答 | 保留已有进展，只标记仍有价值的缺失部分 | 缺失部分很可能改变认识时继续一个具体问题；其余情况暂停 |
| 否定问题前提 | 关闭错误前提及依赖它的认识 | 有新重点时回阶段 1；焦点未变时重新判断 |
| 首次说不清 | 保留已知内容与负担信号 | 存在明显更轻入口时调整一次；其余情况暂停 |
| 再次说不清 | 关闭当前提问目标 | 反映并暂停 |
| 拒绝回答或只想表达 | 立即停止当前提问 | 给予实质反映并保持开放或暂停 |
| 纠正事实或 AI 理解 | 最新表达覆盖旧理解，撤回受影响认识 | 焦点不变时重新判断阶段 2；焦点变化时回阶段 1 |
| 问题太抽象 | 保留方向，只修复表达 | 使用更具体、容易回答的入口；不增加新的定位目标 |
| 方向不对 | 关闭旧方向 | 按焦点纠正回阶段 1 |
| 只说“继续” | 读取 GI-071 的当前未解部分 | 单一方向继续、双候选共同选择，或在缺少方向时保持开放 |

简短回答需要结合上一问和完整有效对话理解。字数不承担用户投入程度或回答质量判断。

## 6. 求建议与决策支持

### 6.1 产品目标

用户问“我该怎么办”“你觉得选哪个”时，AI 始终提供决策支持，帮助用户形成自己的判断。一次合格回应可以整理：

- 用户已经提出的选项；
- 想达到的目标；
- 用户提供的判断依据；
- 现实限制；
- 已知风险；
- 各选项的主要取舍；
- 用户已经显露的倾向。

AI 可以表达条件化匹配，例如：“如果你现在更看重稳定，A 更贴近；如果更想改变现状，B 更贴近。”

### 6.2 提问边界

- 当前材料足以形成决策结构时直接回应；
- 缺少一个会实质改变主要取舍的用户条件时，最多提出一个问题；
- 用户再次要求直接建议时，继续给出更具体的决策结构和用户倾向；
- “答案在你心里”、空泛鼓励、只把问题推回用户、反复询问相同取舍均为失败；
- AI 不新增用户尚未提出的解决方案，不替用户下结论。

### 6.3 认识与日志

- 用户自己的选择、倾向和采纳方向可以进入日志；
- AI 自行增加的方案不进入日志；
- 基于用户证据形成的目标冲突、判断依据和取舍关系可以作为 `ai_synthesized` 认识；
- 用户后续纠正或改变选择时采用最新版本。

## 7. 外部知识问题

劳动规则、医疗判断、关系标签、金融信息等外部知识请求统一视为：

> 尚待核实的决策条件

模型执行以下动作：

1. 保留用户问题及其原有确定程度；
2. 说明这项不确定性怎样影响当前判断、顾虑或选择；
3. 继续帮助用户整理体验、目标、限制和取舍；
4. 需要时提醒用户另行核实或寻求专业支持；
5. 安全风险优先触发全局保护。

模型知识不写成已确认事实、认识或日志内容。用户已经提供的外部说法继续保留其原有确定程度。MCP、实时检索和外部知识工具暂不进入 MVP。

## 8. 焦点、过去经历与独立事件

### 8.1 同一事件内改变重点

保存当前事件内已经成立的认识和重要支线，更新用户工作焦点，并回到阶段 1。事实、认识和日志仍属于同一记录。

### 8.2 过去经历解释当前事件

用户在当前对话中主动把过去经历与当前事件连接时，过去经历可以作为背景证据或支线。AI 保持用户建立的联系，不自行推导稳定人格、长期规律或自动模式。

### 8.3 顺带提到另一独立事件

保留用户原话，同时排除于当前事件的认识与日志。AI 继续当前工作焦点，或在用户明确要求切换时进入下一条规则。

### 8.4 明确切换到另一独立事件

1. 暂停当前访谈；
2. 引导用户生成当前日志或退出当前记录；
3. 当前记录结束后，由用户从新记录入口手动开始；
4. 新记录不继承旧事件的事实、认识和未解部分。

自动切换事件、自动创建记录、跨事件形成认识和混合日志均为硬失败。

## 9. 话题修正规则

话题只调整语言、证据边界、推断范围和风险，不决定固定问题或阶段。

| 话题 | 重点证据与语言 | 主要边界 |
|---|---|---|
| 工作与表现 | 可观察结果、评价标准、可控条件；语言具体 | 限制能力、人格和组织意图推断 |
| 关系与家庭 | 可观察互动、用户感受、期待、位置和边界 | 限制他人动机、关系诊断和代替用户作关系决定 |
| 自我评价 | 具体事件、判断标准、证据和例外 | 限制稳定人格、心理诊断和空泛安慰 |
| 重要选择与行动 | 目标、约束、取舍、优先级和可逆性 | 限制结果预测和代替用户选择 |
| 日常轻片段 | 轻、具体、贴近日常体验 | 控制解释深度，避免拔高意义 |
| 敏感或高压内容 | 跟随用户主动打开的范围，降低回答负担 | 允许随时暂停，排除主动创伤暴露，优先执行安全保护 |

## 10. 模型与产品职责

目标链路为：

> 产品协议 → Interview Skill / Prompt → 大模型自主回应 → 确定性保护 → Trace → Evals 与真人 Preview

### 10.1 产品协议

固定用户任务、白盒顺序、用户控制、来源、安全、事件边界、日志资格和硬失败。

### 10.2 Interview Skill / Prompt

保存高频场景处理原则、话题修正、跨话题正反例和当前阶段策略卡。它帮助模型理解优质回应的共同规律，不把语义判断变成固定脚本。

### 10.3 大模型

结合完整当前对话识别主要回答状态和服务请求，自主选择反映、提问、暂停、回返或收束，并生成自然表达。

### 10.4 确定性保护

稳定执行用户控制、安全、来源、问题次数、单轮一问、事件隔离、输出可用性、可靠提交和失败恢复。

### 10.5 Trace 与评测

每轮最小复核依据增加：

- 当前主阶段；
- 用户工作焦点与来源；
- 当前主要场景；
- 主要回答状态；
- 当前服务请求；
- 纠正和事件边界变化；
- 使用的话题修正；
- 最终动作及原因；
- 回应后认识、焦点、阶段和日志资格的变化。

完整候选列表、数字评分、逐项权重、固定心理分类和隐藏思维过程不列为 MVP 运行记录。

## 11. 代表案例

### 11.1 完整回答后直接形成认识

上一问：“你担心这次拒绝会带来什么？”

用户：“我担心领导以后觉得我不愿意配合，但我也知道这次临时加活会打乱已经答应家人的安排。”

合格动作：吸收“工作评价”和“家庭承诺”的取舍，直接形成认识或进入决策支持，不重复询问担心什么。

### 11.2 部分回答只补有价值缺口

用户已经说清两个选项和现实限制，只缺“当前最不能承受的代价”。这一条件会实质改变取舍时，AI 可以提出一个具体问题；其他背景不继续收集。

### 11.3 否定前提后撤回旧方向

AI 询问“你是不是担心自己做不好”，用户回答“我不担心能力，我只是不同意这个目标”。AI 关闭能力前提，采用“目标分歧”作为新重点并回阶段 1。

### 11.4 首次与再次说不清

用户第一次说“不知道”时，AI 存在更轻入口，可以改问一个具体时刻或两项可辨认取舍；用户再次说不清时，AI 反映当前状态并暂停。

### 11.5 只想表达

用户说“我现在只想把这股委屈说出来，不想分析”。AI 停止提问，围绕具体委屈提供实质反映并保持开放。

### 11.6 首次求建议

用户问“我该不该辞职”，并已提出“留下”与“离开”两个选项。AI 整理用户目标、现实限制、风险和主要取舍，可以给出条件化匹配；当前信息足够时直接回应。

### 11.7 再次要求直接建议

用户说“别分析了，你直接告诉我选哪个”。AI 进一步说清哪一选择更贴近用户已表达的优先级和可承受代价，继续帮助用户形成判断，不增加新方案或代替用户决定。

### 11.8 外部知识请求

用户问“这种情况劳动法怎么规定”。AI 将其标记为待核实条件，说明“规则是否支持解除或补偿”会怎样改变风险判断，并继续帮助用户整理当前证据、顾虑和取舍；模型不输出法律事实。

### 11.9 同一事件换重点

用户从“是否辞职”改为“我真正卡住的是怎么和领导开口”。AI 保存当前事件内已有取舍认识，回阶段 1 对齐新的工作焦点。

### 11.10 明确切换独立事件

用户说“先不聊同事了，我想改说昨天和家人的争执”。AI 暂停当前访谈，引导生成当前日志或退出；完成后由用户手动开始新记录，新记录不继承旧事件内容。

### 11.11 关系话题

用户说伴侣没有回复消息。AI 可以探索可观察互动、用户感受、期待和边界，不把“对方不在乎你”写成事实。

### 11.12 自我评价

用户说“我就是一个很失败的人”。AI 把标签落回本次事件、用户采用的判断标准、支持证据和例外，不扩展为稳定人格结论。

### 11.13 复合场景

用户先纠正“我不在意工资”，随后问“那我该怎么选”。AI 先撤回以工资为核心的旧取舍，再用更新后的目标和限制提供决策支持。

## 12. 硬失败

以下任一项成立即判失败：

- 重复索取用户已经回答的内容；
- 部分回答后重新收集全部背景；
- 忽略事实、认识或焦点纠正；
- 用户否定前提后继续同义追问；
- 首次说不清后增加回答负担，再次说不清后继续追问；
- 用户只想表达时继续提问；
- 求建议时只给空泛反问或“答案在你心里”；
- AI 新增解决方案、直接替用户决定或预测结果；
- 回答外部事实，或把模型知识写入认识和日志；
- 调用 MCP、实时检索或外部知识工具；
- 自动切换事件、自动创建新记录、跨事件形成认识或混合日志；
- 新记录继承旧事件的事实、认识或未解部分；
- 断言他人动机、稳定人格或心理诊断；
- 为关系、自我评价、重要选择和敏感内容建立固定脚本；
- 一轮提出多个正式问题或推进多个主要方向；
- 忽略停止、生成日志、结束当前记录或安全信号；在当前记录内改变模式或跨模式继承；
- 使用固定心理分类、数字评分或程序化语义路由替代模型判断。

## 3. 已确认的四项原则

### D-B08｜单次事件保持事件口径

推荐选择：**采用严格事件口径。**

规则：

- 原话只描述一次经历时，成果使用“这次、当时、在这件事里”等当前事件表达。
- 原话明确包含“总是、每次、通常、经常、一……就……”等重复性证据时，才允许整理为稳定规律。
- 模型的高置信度不能替代用户提供的重复性证据。

示例：

| 原文字 | 推荐改写 |
|---|---|
| 胸口收紧会让我一直屏气，离开现场后才松下来。 | 这次胸口收紧时，我一直屏着气，直到走出会议室才松下来。 |
| 被打断、没能说完时，我会同时委屈和生气。 | 这次被打断、没能把话说完，我同时感到委屈和生气。 |
| 有提前留出的半小时，后面就不用一直赶。 | 这次提前留出的半小时，让后面没那么赶。 |

备选：允许AI在一次事件中概括稳定规律。该选择表达更凝练，也会增加过度归纳风险。

### D-B09｜诚实边界保留已经确认的最小认识

推荐选择：**自然回应承认已确认事实，成果资格继续执行现有门槛。**

规则：

- 用户已经说清一个直接感受、念头、互动或行动事实时，收束语先承认这项最小认识。
- 材料不足以形成新增洞见时，角度仍按`honest_limit`收束，不进入日志中的“我看见的”。
- 自然理解、回应和成果资格保持三者一致：用户能感到回答被接住，日志也不会把单一事实包装成洞见。

示例：

> 目前最确定的是害怕，更多部分暂时还说不清，我们先停在这里。

备选：继续使用“这部分还不急着说成一个结论”。该选择边界简洁，也会覆盖用户已经说清的最小认识。

### D-B10｜短回答必须带回所回应的目标

推荐选择：**优先保留问题上下文。**

规则：

- “没有、不知道、想不起来、说不清”等短回答，需要结合当前唯一问题形成自然理解。
- 当前问题目标清楚时，理解层明确用户否定或未知的是哪一项。
- 历史上下文缺失或问题包含多个命题时，使用通用边界承接并停止继续推断。

示例：

- “没有”回应具体时刻：`你说没有更具体的时刻了。`
- “想不起来”回应具体时刻：`你暂时想不起更具体的时刻了。`
- 回应继续保持：`这件事已经先记下来了。`

备选：所有短边界统一使用“好，这部分先停在这里”。该选择一致性高，也会减少用户可验证的理解信息。

### D-B11｜关系位置通过可观察互动来回答

推荐选择：**把抽象位置转成一次具体互动中的可观察信号。**

规则：

- 用户已经表示“还没想清自己处在什么位置”时，AI改用具体互动问法。
- 下一问落到对方怎样回应、双方怎样说话、谁能做决定、什么边界被尊重等可观察互动。
- 每轮只问一个信号；用户仍说不清时按文本边界收束。

推荐问法：

> 先回到刚才那次互动。对方怎样回应时，你会更清楚自己在这段关系中的位置？

更低压力版本：

> 先不用概括这段关系。刚才那次互动里，哪种回应会让你更有平等说话的感觉？

备选：继续直接询问“希望自己处在怎样的位置”。该选择保持概念纯粹，也会提高抽象表达负担。

## 贯穿案例

四篇文章都沿着 Daily Light 的 AI 访谈主链路展开。

`产品想法 → 提示词原型 → 单次访谈 → 状态与日志问题 → 结构化访谈系统 → 评测与发布闭环`

Daily Light 的产品细节只承担案例作用。系列文章的主线是个人创作者怎样定义任务、组织上下文、委托 AI、检查中间结果，并用证据决定下一步。

## 核心方法

`定义问题 → 组织上下文 → 委托小任务 → 检查中间结果 → 验证用户价值 → 沉淀下一轮`

## 材料口径

- 同期记录包括 Cc、Cx、提示词和 Git 提交。
- 后续理解包括 PRD、架构选择、对话链路和评测框架。
- 当前沉淀以仓库中的 AGENTS、方法论文档和现有测试体系为准。
- 个人判断只建立在前述材料之上，并保留适用边界。

具体材料与时间线见 [材料与证据](https://my.feishu.cn/docx/Ro9rdByfao2jxNxO9P2cUeMGnQf)。

## 1. 当前问题

v1.4 八题均技术有效，中位耗时 `2701.5ms`。Codex 初评 `6 pass / 1 minor / 1 fail`：模型已经减少第三方原因推断，但仍会把用户已经回答的信息层拆成更细的近义选项，然后误认为这是新增信息。

这个问题同时出现在普通幸福表达和纠正后继续场景，属于跨案例的目标选择缺陷。当前比较案例继续只承担最后回归职责。

## 2. 首个单因素

候选身份：`2026-08-20.gi088-complete-response-first-v1-5-semantic-layer-coverage`

运行身份：`2026-08-20.gi088-complete-response-first-v1-5-semantic-layer-coverage-quality-v1`

输出前按以下信息层盘点完整有效对话：

- 事件与触发；
- 感受与身体反应；
- 想法、判断与解释；
- 需要、价值与期待；
- 行为与回应；
- 关系位置与意义；
- 变化、规律与例外；
- 影响与下一步。

用户已经清楚回答的信息层视为覆盖。换成更细、近义或二选一的说法，仍属于同一已覆盖层。新增目标必须选择一个尚未回答、与当前意图相关且容易回答的信息层。

承接部分只自然转述用户明确表达的内容。原因、动机、目标和第三方心理缺少直接原文时不能进入陈述；需要确认时只能成为本轮唯一问题，并且问题必须属于未覆盖层。

## 3. 固定条件与边界

- 继承 v1.4 纯文本、单气泡、一次可见调用和问号观察规则。
- `deepseek-v4-pro`、Thinking disabled、Temperature `0.2`、`1280` Token、45 秒硬门、完整上下文保持固定。
- 同一 `3＋5`，新预算 `8` 次；并发 `1`，重试、恢复和回退 `0`。
- 严重泄漏、忽略明确停止、连续两次技术失败或预算失控立即停止；普通内容问题整批后判断。
- 程序只判断来源、控制、预算、超时、隐私、幂等和写入；信息层是否真的覆盖继续由模型方法和原文评审承担。

## 4. 质量与发布门

- 技术：八题正文完整、单例不高于 `15s`、无截断。
- 内容：五个硬案例全部 pass，全体零 fail、最多一个 minor。
- 稳定性：首批通过后再用同方法做一次不同采样的代表性复验，避免单批偶然通过。
- 质量稳定后接入最多一次后台状态调用和隔离 Preview；后台不能改变本轮可见回复。
- 页面验收通过后执行全量测试、构建、Prisma、提交、推送、Production 切换和 baseline 回退验证。

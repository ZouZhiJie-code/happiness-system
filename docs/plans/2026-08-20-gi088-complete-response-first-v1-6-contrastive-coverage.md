## 1. 当前问题

v1.5 八题均技术有效，中位耗时 `3509ms`。Codex 初评 `6 pass / 1 minor / 1 fail`：文字规则已经列出信息层，但模型仍会把明确说出的感受细分成近义选项，并默认回到感受问题。

该问题同时出现在普通幸福表达和十六条消息的长上下文，已经具备跨案例证据。当前比较案例继续只承担最后回归职责。

## 2. 首个单因素

候选身份：`2026-08-20.gi088-complete-response-first-v1-6-contrastive-coverage`

运行身份：`2026-08-20.gi088-complete-response-first-v1-6-contrastive-coverage-quality-v1`

继承 v1.5 的语义层覆盖方法，只增加两个跨场景对比例子：

- 用户已经明确说出感受与身体反应时，同义细分、强度排序和二选一仍属于已覆盖层；下一入口应转向尚未回答的影响、期待、行为、规律或其他相关层。
- 上一问就是感受、当前用户已经回答时，禁止再次询问“最强烈的感觉是什么”；应吸收答案并进入一个真正未答层。

例子使用与八题正文不同的人物和事件，只展示通用边界。模型仍负责判断语义层和自然表达；程序不把感受词或问句写成关键词拦截。

## 3. 固定条件与边界

- 纯文本、单气泡、一次可见调用、完整上下文和问号观察保持固定。
- `deepseek-v4-pro`、Thinking disabled、Temperature `0.2`、`1280` Token、45 秒硬门保持固定。
- 同一 `3＋5`，新预算 `8` 次；并发 `1`，重试、恢复和回退 `0`。
- 严重泄漏、忽略明确停止、连续两次技术失败或预算失控立即停止；普通内容问题整批后判断。
- 程序继续只判断来源、控制、预算、超时、隐私、幂等和写入；语义层是否真的已回答由模型方法和原文评审承担。

## 4. 质量门与退出规则

- 技术：八题正文完整、单例不高于 `15s`、无截断。
- 内容：五个硬案例全部 pass，全体零 fail、最多一个 minor。
- 首批通过后，用相同方法建立独立稳定性复验身份；通过后才进入后台状态和隔离 Preview。
- 若本批仍出现同层重复，纯提示方法到此停止；下一单因素改为模型能力比较，不继续增加提示规则或案例特例。

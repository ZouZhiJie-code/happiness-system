## 4. 参考研究与方案取舍

- [GitHub Markdown 官方说明](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#relative-links)建议仓库内文件使用相对链接，克隆后仍可导航。
- [Docusaurus 的坏链接策略](https://docusaurus.io/docs/api/docusaurus-config#onBrokenLinks)将坏链接作为构建期确定性门禁。
- [Lychee](https://github.com/lycheeverse/lychee)提供全仓链接检查、排除与锚点检查能力；其社区记录显示应用根路径和锚点可能产生误报。

因此，本项目第一版门禁使用仓库内 Node 脚本，不增加依赖，只检查本地文件链接、核心文档字段、状态词和唯一执行入口。应用页面路径、外链和标题锚点暂不作为阻断项。
